键盘模拟输入器：在文本框里输入内容，倒计时结束后自动把内容模拟键入到目标窗口。

## 下载

| 文件 | 适用机器 |
|---|---|
| `Type-1.5.4-windows-amd64.zip` | 常规 PC（Intel / AMD 处理器） |
| `Type-1.5.4-windows-arm64.zip` | Windows on ARM（骁龙等 ARM 处理器） |

解压后双击 `Type.exe` 即可，单文件、无需安装。拿不准就选 amd64。

## 本次变化

### 缺少 WebView2 运行时时，程序会告诉你怎么办

Type 的界面由 Windows 上的 WebView2 运行时渲染。少数 Windows 10 设备没有装它，以往这种机器上双击之后什么都不会发生：窗口建不出来，程序又没有控制台，内部的报错没有任何人看得到，只会让人以为文件坏了。

现在启动前会先检查运行时，缺少或起不来都会弹一次说明：点"是"打开微软官方下载页，装好后重新运行 Type 即可，不必重启电脑；点"否"直接退出。

### 界面被刷新后会自动接回正在进行的任务

按了 Ctrl+R/F5，或者浏览器内核崩溃后自行恢复时，界面不会再显示成"什么都没在干"。进度、状态和取消按钮都会接回正在进行的那个任务，不会再出现"界面是空闲的、取消按钮是灰的、可实际上正在往目标窗口里输入"。

### 剪贴板原内容没换回来时会明确说明

粘贴模式结束后要把剪贴板恢复成你原来的内容。这一步现在更耐心：被别的程序短暂占用时会多试几次，通常就能成功。万一仍然失败，状态栏会写明"剪贴板未恢复"，不会让你以为原先复制的东西还在。

另外，个别罕见格式（元文件图形、所有者绘制、GDI 对象类）不再被搬进快照。它们照抄下来恢复时会变成失效的句柄，留在剪贴板里反而会害到别的程序。

### 发布版不再保留调试能力

正式发布的 Type.exe 关闭了网页开发者工具与右键菜单。开发构建（`-tags dev`）不受影响，本地调试照旧。

## 使用提醒

- Windows 10 上若首次启动弹出缺少 WebView2 运行时的提示，按指引装一次即可，之后不再出现；Windows 11 预装，不会看到它。
- 输入期间请保持目标窗口在前台：一旦切走，输入会立即停止。这是 1.5.3 引入的行为，本次未变。
