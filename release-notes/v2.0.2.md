## 下载

| 文件 | 适用机器 |
|---|---|
| `Type-2.0.2-windows-amd64.zip` | 常规 PC（Intel / AMD 处理器） |
| `Type-2.0.2-windows-arm64.zip` | Windows on ARM（骁龙等 ARM 处理器） |

解压后双击 `Type.exe` 即可，单文件、无需安装。拿不准就选 amd64。

## 本次变化

这一版是内部维护版本，界面、输入行为、全部文案和快捷键都没有变化。

把仓库自带的窗口框架换回了与上游一致的完整副本。此前框架被精简过，只保留了窗口与 WebView2 宿主；精简本身是有效的（产物从 10.4 MB 降到 7.6 MB），但它同时改动过窗口创建与页面加载的几个文件，排查问题时多一层不确定因素。恢复全量之后，本仓库与上游 v0.7.4 的框架代码完全一致，后续再遇到窗口或页面起不来的问题，可以直接对照上游。

README 同步补了一条排障说明：如果 `Type.exe` 所在目录被沙箱或安全工具标成了低完整性，程序会以低完整性启动，WebView2 写不了自己的用户数据目录，结果就是窗口能创建、里面却是空的——看起来像双击没反应。修法是 `icacls "<目录路径>" /setintegritylevel (OI)(CI)Medium`，然后重新编译或重新复制 exe；已经存在的 exe 不会因为目录改标签而跟着变。

## 使用提醒

- **升级方式**：直接替换旧版 `Type.exe` 即可，没有配置或数据需要迁移。
- **体积**：恢复全量框架后单文件从 7.6 MB 涨到约 10 MB，这是完整框架的代价。
- **已知限制与上一版一致**：跨显示器拖动不重新适配缩放（重启恢复）、手动选择的主题不跨启动保留、提权窗口需要以管理员身份运行 Type。详见仓库 README 的「已知限制」。
