键盘模拟输入器：在文本框里输入内容，倒计时结束后自动把内容模拟键入到目标窗口。

## 下载

| 文件 | 适用机器 |
|---|---|
| `Type-1.5.3-windows-amd64.zip` | 常规 PC（Intel / AMD 处理器） |
| `Type-1.5.3-windows-arm64.zip` | Windows on ARM（骁龙等 ARM 处理器） |

解压后双击 `Type.exe` 即可，单文件、无需安装。拿不准就选 amd64。

## 本次变化

### 焦点漂移防护：键入途中目标窗口被切走会立即停止

以往一旦开始输入，程序就会一路打完，即使中途切到了别的窗口，内容会落进错误的地方。现在每个字符注入前都会确认目标窗口仍是倒计时结束时锁定的那一个：

- 切到别的程序、目标程序弹出模态窗口、或切回 Type 自身，都会**立即停止**，终态说明已经输入了多少字，不会再把剩余内容打进错误的窗口；
- 中文走的剪贴板路径同样处理：写入剪贴板前、粘贴前各确认一次；若在粘贴的瞬间发生切换，会如实报"粘贴结果无法确认"，剪贴板里原有的内容照旧恢复；
- 判定看的是窗口本身而不是标题，同一个窗口里标题变化（例如网页标题更新）不会误停。

### 倒计时预览更跟手，取消更快

- 目标窗口预览改为 0.1 秒级采样：你切到哪个窗口，下一拍就显示哪个；
- 点"取消"最多 0.1 秒内生效（此前最坏要等满 1 秒）；
- 倒计时的秒数、提示文案与总时长与之前完全一致。

### 发布包在发布前逐项校验

每个发布包构建完成后都会读回核对：CPU 架构、版本号、图标、高分屏（DPI）声明。少任何一项都不会发布，避免出现"能运行但图标空白、属性里没有版本号"的包。

## 使用提醒

- 从 1.5.2 升级后，**输入期间请保持目标窗口在前台**：一旦切走输入就会停止（这正是本次改动的目的）。
- 该防护的判定只到"窗口"这一层：在同一个窗口里切换到另一个输入框（网页、代码编辑器里点另一个输入框），或切换浏览器的标签页，都不会中止输入。标签页不是窗口，切换时窗口层面完全不变。这一条已写入 README 的「已知限制」。
