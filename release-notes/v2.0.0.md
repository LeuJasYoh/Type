键盘模拟输入器：在文本框里输入内容，倒计时结束后自动把内容模拟键入到目标窗口。

## 本次变化

这一版换掉了窗口宿主层：原来由程序自己调用 Win32 摆放窗口、换算 DPI、管理单实例，现在这些交给 mygo 框架。**输入行为、界面布局、全部文案与快捷键都没有变化**，改的是「窗口怎么出现、怎么被管理」。

### 打开更快，不再闪白

窗口不再先以系统默认位置出现、再跳到你面前，也不再在页面绘制前显示约 0.1 秒的白底。

本机实测（Windows 11、125% 缩放）：

| 指标 | 1.7.4 | 2.0.0 |
|---|---|---|
| 窗口首次可见 | 0.51 ~ 0.66 秒 | 0.06 ~ 0.09 秒 |
| 出现时的位置跳变 | 从系统层叠位跳到居中（30~40 毫秒可见） | 一开始就在居中位置，0 次跳变 |
| 页面绘制前的白屏 | 有，约 160 毫秒 | 无，全程按主题底色绘制 |

标题栏与窗口边框现在跟随系统深浅色，暗色主题下不再有一条亮白的标题栏。

### 单实例改为静默转交

同时仍然只允许运行一个实例，但第二个实例的行为变了：

- 以前：弹出「已有实例」提示框，需要手动关掉。
- 现在：把命令行参数转交给已经在跑的实例后自行退出，不弹窗；已有窗口只闪一下任务栏，**不会把自己抢到前台**。这一条是刻意的：Type 靠前台窗口锁定注入目标，此时抢前台会让正在进行的输入触发「目标窗口已切换」而中断。

### 体积增大到约 7.2 MB

从 3.67 MB 增到 7.2 MB，这是本次唯一的明显退步。原因不是新增功能，而是新框架把窗口、DPI、单实例、原生对话框等能力放在同一个包里，Go 只能整包链接，用不到的部分也进不了裁剪范围。

已经做过一轮精简（未精简时 10.42 MB，删掉 Type 用不到的 TypeScript 生成器、自动更新、HTTP 协议层与内容拦截后降到 7.2 MB），剩下的主要是运行时与标准库的连带开销。单文件、零运行时依赖、无需安装这些特性都没有变。

### 仓库与构建

- Go 工具链更新到 1.27.3；窗口层依赖从 go-webview2 换成 mygo v0.7.4（MIT，纯 Go，构建仍不需要 C 工具链）。
- 自研的窗口尺寸、DPI 换算、图标提取、单实例互斥体代码全部删除，`internal/win32` 收窄为只负责键盘注入、剪贴板与前台窗口检测。
- 仓库测试、前端检查与产物读回校验全部通过。

## 使用提醒

- **升级方式**：直接替换旧版 `Type.exe` 即可，没有配置或数据需要迁移。
- **单实例**：若你已经开着一个 Type，再双击不会弹提示框，而是闪一下任务栏。这是本版的预期行为。
- **已知限制与上一版一致**：跨显示器拖动仍不重新适配缩放（重启恢复）、手动选择的主题不跨启动保留、提权窗口需要以管理员身份运行 Type。详见仓库 README 的「已知限制」。
