## 本次变化

修掉一个界面显示问题：在部分分辨率与显示缩放组合下，窗口底部的选项行、启动与取消按钮、状态栏会被裁掉，看起来像控件消失了。用 Ctrl 加鼠标滚轮把页面缩回 100% 又会恢复正常，这个现象正好指向原因。

原因是页面里的控件尺寸按固定的像素写死，而系统缩放、显示器工作区或页面缩放会让可用的页面视口小于设计尺寸。视口一变小，多出来的部分就被窗口裁掉，页面自己又没有为小视口准备退路。

这一版做了两处改动：

- 启动时把页面缩放复位到 100%，避免上次留下的缩放级别让刚打开的窗口就不在正确比例上。滚轮与键盘缩放仍然可用，和以前一样。
- 页面视口小于设计尺寸时，收紧输入区的高度下限与四周留白，并放开页面根元素的最小尺寸限制。540×480 及更大的窗口一像素不变，只有低于这个尺寸才生效。

本机实测（Windows 11、125% 缩放）：正常情况下页面视口是 540×480，状态栏贴底、没有溢出；用 Ctrl 加滚轮放大一档后视口变成 491×436，状态栏仍在可见范围内，页面没有出现滚动条；反向滚轮回到 540×480。另用强制 1.75 倍设备缩放复现极端组合，视口被压到 386×343，横向与纵向同样没有裁切。

输入行为、全部文案、快捷键与单实例规则都没有变化。

## 使用提醒

- **升级方式**：直接替换旧版 `Type.exe` 即可，没有配置或数据需要迁移。
- **已知限制与上一版一致**：跨显示器拖动仍不重新适配缩放（重启恢复）、手动选择的主题不跨启动保留、提权窗口需要以管理员身份运行 Type。详见仓库 README 的「已知限制」。
