键盘模拟输入器：在文本框里输入内容，倒计时结束后自动把内容模拟键入到目标窗口。

## 下载

| 文件 | 适用机器 |
|---|---|
| `Type-1.7.4-windows-amd64.zip` | 常规 PC（Intel / AMD 处理器） |
| `Type-1.7.4-windows-arm64.zip` | Windows on ARM（骁龙等 ARM 处理器） |

解压后双击 `Type.exe` 即可，单文件、无需安装。拿不准就选 amd64。

## 本次变化

### 界面换成液态玻璃风格

窗口底色改为冷调深色，强调色只用一种青色；输入区、状态栏和目标窗口条改成半透明玻璃，浅色主题使用同一套配方。标题栏、按钮、滑块与状态点重新配色，空闲时状态栏显示「就绪」。

窗口结构、控件顺序和全部既有文案没有变化，输入行为不受影响。界面仍是 Vue 3 + Vite 打包的单文件，没有新增运行时依赖。

### 剪贴板写入与恢复更可靠

这一版重做了剪贴板写入与恢复的时机，减少原内容丢失的可能：

- 写入剪贴板前先把需要的内存准备好，准备失败时不再清空原内容。
- 写入过程中途失败，会在同一次打开剪贴板期间回滚。
- 粘贴后的内容核对与快照恢复合并到同一次打开剪贴板里完成，避免检查和恢复之间覆盖用户新复制的内容。
- 用户已经复制了新内容时跳过恢复；读不到或恢复失败时，仍会明确提示原内容可能已丢失。
- 内部接口随这些时机一起调整，用户可见的提示文案保持不变。

### 仓库与构建

- Go 工具链更新到 1.26.10，x/sys 更新到 v0.49.0，govulncheck 不再有未清零项。
- 前端样式、状态栏组件与仓库文档同步更新，浅色与深色截图重新生成。
- 仓库测试与前端检查全部通过。

## 使用提醒

- 用法与 1.7.3 相同：倒计时结束后开始输入，输入期间保持目标窗口在前台。
